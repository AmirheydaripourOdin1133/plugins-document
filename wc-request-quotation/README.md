## قابلیت‌ها

### فرانت (مشتری)

- دکمه **«درخواست پیش‌فاکتور»** در صفحهٔ محصول ساده و متغیر
- پاپ‌آپ فرم: نام، تماس، شرکت، کد ملی/اقتصادی، تعداد
- چک‌باکس **نیاز به تماس کارشناس** (متن قابل تنظیم در ادمین)
- تولید و دانلود PDF بلافاصله پس از ثبت
- پشتیبانی از جدول وریشن (`woo-variations-table-grid`): ستون **کانفیگ** فقط برای محصول متغیر در PDF

### ادمین

- نوع پست `quotation_request` — لیست درخواست‌ها با ستون‌های سفارشی
- متاباکس **اطلاعات پیش‌فاکتور** (جزئیات مشتری و محصول)
- متاباکس **مدیریت PDF** (دانلود، ساخت مجدد، حذف)
- متاباکس **پیگیری تماس** (وضعیت تماس + گزارش مختصر)
- رنگ‌بندی لیست: تماس جدید / در انتظار / تماس گرفته‌شده
- ویجت پیشخوان: درخواست‌های در انتظار تماس
- شمارنده در منوی ادمین (مشابه سفارش جدید)

## نصب

1. پوشهٔ `wc-request-quotation` را در `wp-content/plugins/` قرار دهید.
2. از **افزونه‌ها** افزونه را فعال کنید.
3. مطمئن شوید **WooCommerce** فعال است.
4. منوی **تنظیمات پیش‌فاکتور** را برای آدرس، مالیات، شبا و … تکمیل کنید.
5. پوشهٔ `wp-content/uploads/quotations/` باید قابل نوشتن باشد (خودکار ساخته می‌شود).

### وابستگی‌های پیشنهادی (سایت رسام)

| افزونه | نقش |
|--------|-----|
| WooCommerce | محصولات و قیمت |
| woo-variations-table-grid | جدول وریشن + دکمه پیش‌فاکتور per row |
| rasam-server-config | نمایش RTL جزئیات در ادمین + پیکربندی سفارشی |

## تنظیمات

مسیر: **تنظیمات پیش‌فاکتور** (منوی سایدبار وردپرس)

| فیلد | کاربرد |
|------|--------|
| آدرس / تلفن / کد پستی / کد اقتصادی | سربرگ PDF |
| URL وب‌سایت | سربرگ PDF |
| شماره شبا / کارت / نام بانک | بلوک پرداخت PDF |
| درصد مالیات | محاسبه مالیات در PDF |
| متن توضیحات فاکتور | پاورقی PDF (مثلاً اعتبار ۲۴ ساعته) |
| متن تیک «نیاز به تماس» | برچسب چک‌باکس در پاپ‌آپ |

## جریان کار فرانت

```
کلیک «درخواست پیش‌فاکتور»
    → پاپ‌آپ فرم
    → AJAX: wc_rq_submit_form
    → ایجاد quotation_request + متادیتا
    → generate_pdf_invoice()
    → باز شدن PDF در تب جدید
```

### محصول متغیر (جدول وریشن)

- `is_variable = 1` ارسال می‌شود
- نام محصول به صورت `عنوان (مشخصات وریشن)` ذخیره می‌شود
- در PDF ستون **کانفیگ** نمایش داده می‌شود

### محصول ساده

- `is_variable = 0`
- در PDF فقط ستون **نام محصول** (بدون کانفیگ)

## جریان کار ادمین

### لیست درخواست‌ها

`ویرایش → درخواست‌های پیش‌فاکتور`

| ستون | توضیح |
|------|--------|
| عنوان | نام پیش‌فاکتور + برچسب «نیاز به تماس» |
| نام مشتری / شماره تماس | از متادیتا |
| تماس | badge رنگی وضعیت |
| مبلغ کل | جمع آیتم‌ها |
| تاریخ | تاریخ انتشار |

### صفحهٔ ویرایش

- **اطلاعات پیش‌فاکتور** — دادهٔ مشتری و خط محصول (با RTL در صورت فعال بودن `rasam-server-config`)
- **پیگیری تماس** — تیک «تماس گرفته شد» + فیلد گزارش
- **مدیریت PDF** — عملیات فایل

## ذخیره‌سازی PDF و دیتابیس

### مسیر فایل‌ها

```
wp-content/uploads/quotations/quotation-{post_id}.pdf
```

### متای مسیر PDF

- کلید: `rq_pdf_path` — مسیر کامل فایل روی سرور

### حذف خودکار (مهم)

| رویداد | رفتار فعلی |
|--------|------------|
| حذف درخواست (پست) | فایل PDF همراه پست حذف می‌شود (`before_delete_post`) |
| حذف دستی از ادمین | دکمه «حذف PDF» در متاباکس |
| **گذشت زمان (مثلاً ۱ ماه)** | **وجود ندارد** — فایل‌ها تا حذف دستی یا حذف پست باقی می‌مانند |

> برای جلوگیری از سنگین شدن هاست، در نسخه‌های بعدی می‌توان **WP-Cron** با تنظیم «حذف PDFهای قدیمی‌تر از X روز» اضافه کرد (فقط فایل یا همراه پست — قابل بحث).

### امنیت دسترسی PDF

- URL فایل‌ها از طریق `uploads/quotations/` در دسترس است اگر مسیر حدس زده شود.
- پیشنهاد آینده: دانلود از طریق endpoint ادمین با capability یا نام فایل تصادفی.

## ساختار فایل‌ها

```
wc-request-quotation/
├── wc-request-quotation.php      # bootstrap اصلی + کلاس WC_Request_Quotation

├── assets/
│   ├── style.css                 # استایل پاپ‌آپ فرانت
```

## یکپارچگی با Rasam Server Config

افزونه `rasam-server-config`:

- متاباکس پیش‌فرض `rq_meta_box` را با نسخهٔ RTL (`rsc_rq_meta_box`) جایگزین می‌کند
- جزئیات وریشن و قطعات اضافه را پارس می‌کند

افزونه پیش‌فاکتور **همیشه** متاباکس `rq_meta_box` را ثبت می‌کند؛ اگر RSC فعال نباشد، همان نسخهٔ پایه نمایش داده می‌شود.

## عیب‌یابی

### پیام «۳ کاراکتر غیرمنتظره» هنگام فعال‌سازی

**علت:** فایل PHP با **UTF-8 BOM** ذخیره شده (معمولاً `includes/class-wc-rq-support.php`).

**راه‌حل:**

1. در ویرایشگر encoding را **UTF-8 without BOM** کنید
2. از نسخهٔ 2.2.3+ لودر `wc_rq_load_include_file` BOM را حذف می‌کند
3. افزونه را غیرفعال و دوباره فعال کنید

### AJAX «ارسال ناموفق» یا خرابی AJAX سایر افزونه‌ها

همان علت BOM — خروجی قبل از JSON. پس از رفع BOM و پاک کردن کش، باید برطرف شود.

### استایل لیست ادمین (badge / رنگ ردیف) نمایش داده نمی‌شود

- کش مرورگر و WP Rocket را پاک کنید
- بررسی کنید `assets/admin-support.css` لود می‌شود (نسخه در query string)

### فیلد گزارش تماس فقط بعد از ذخیره باز می‌شود

- `assets/admin-support.js` باید در صفحهٔ ویرایش لود شود
- با تیک زدن «تماس گرفته شد» باید بلافاصله باز شود (بدون ذخیره)

## توسعه و نگهداری

### هوک‌های AJAX

| action | دسترسی |
|--------|--------|
| `wc_rq_submit_form` | مهمان + کاربر |

### ثابت‌ها

```php
WC_RQ_PLUGIN_FILE  // مسیر فایل اصلی افزونه
```

### کلاس‌ها

- `WC_Request_Quotation` — CPT، PDF، فرم، تنظیمات
- `WC_RQ_Support` — تماس و UI ادمین

### نکات کدنویسی

- فایل‌های `includes/*.php` را **فقط** با UTF-8 بدون BOM ذخیره کنید
- پس از تغییر CSS/JS نسخه enqueue را در `wc-request-quotation.php` افزایش دهید
- TCPDF سنگین است؛ فقط هنگام `generate_pdf_invoice` لود می‌شود

### تست دستی پیش از انتشار

- [ ] محصول ساده — PDF بدون ستون کانفیگ
- [ ] محصول متغیر از جدول — PDF با کانفیگ
- [ ] چک‌باکس تماس + لیست ادمین
- [ ] ساخت مجدد / حذف PDF از ادمین
- [ ] فعال‌سازی افزونه بدون هشدار BOM
